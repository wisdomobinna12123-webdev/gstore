# 🛍️ Gstore - Premium Men's Boutique 

**Gstore** is a modern, responsive e-commerce website designed for a premium men's boutique. Built with pure HTML, CSS, and JavaScript - no frameworks required. Features a sleek dark theme with green accents, WhatsApp ordering system, and a complete shopping cart experience.

## ✨ Features

### 🎨 Design & UI
- **Dark/Light Mode Toggle** - Persistent theme preference with smooth transitions
- **Minimalist Premium Design** - Clean, modern aesthetic with green accent color
- **Fully Responsive** - Mobile-first approach, works seamlessly on all devices
- **Smooth Animations** - Floating elements, hover effects, and subtle transitions
- **Custom Scrollbar** - Styled for better user experience
- **Accessible** - Semantic HTML, ARIA labels, keyboard navigation

### 🛒 Shopping Experience
- **54 Premium Products** across 6 categories
- **Advanced Cart System** - Add/remove items, adjust quantities
- **Persistent Storage** - Cart saved to localStorage
- **Real-time Updates** - Dynamic price calculations
- **Quantity Controls** - Plus/minus buttons for each cart item
- **Keyboard Shortcuts** - Ctrl/Cmd + K to toggle cart

### 💬 WhatsApp Integration
- **Direct Product Ordering** - Pre-filled WhatsApp messages for each product
- **Cart Checkout** - Complete order summary sent via WhatsApp
- **Formatted Messages** - Professional order format with totals
- **Quick Response** - Instant connection to customer service

### 🤝 Customer Support
- **Live Chat Widget** - Interactive customer care interface
- **Quick Questions** - Pre-defined buttons for common queries
- **Typing Indicators** - Realistic chat experience
- **Newsletter Subscription** - Email capture for marketing
